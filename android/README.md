# SmartVoice Android

تطبيق Android أصلي مبني باستخدام Kotlin وJetpack Compose.

## المتطلبات
- Android Studio حديث يدعم Android Gradle Plugin 8.7.3.
- JDK 17.
- Android SDK Platform 35.

## فتح المشروع
1. افتح Android Studio.
2. اختر **Open** وحدد مجلد `android/` داخل المستودع.
3. انتظر مزامنة Gradle.
4. شغّل مهمة `app > Tasks > build > assembleDebug` أو شغّل التطبيق على جهاز/محاكي.

## الحزمة
`com.smartvoice.intelligence`

## الحالة الحالية
هذه نسخة تأسيسية للواجهة العربية واتجاه RTL. زر التسجيل معطّل عمداً حتى لا يوحي بأن التسجيل والتفريغ أصبحا جاهزين قبل بناء صلاحيات الميكروفون وإدارة الملفات واختبارهما.

## الخطوات التالية
1. تنفيذ التسجيل الصوتي المحلي مع موافقة صلاحية الميكروفون.
2. حفظ التسجيلات وإظهار سجلها.
3. إضافة التفريغ النصي مع الطوابع الزمنية.
4. بناء محرك فهم السياق وتوجيه العناصر إلى أقسام التطبيق.
5. إضافة قاعدة بيانات محلية ومراجعة العناصر غير المؤكدة.
