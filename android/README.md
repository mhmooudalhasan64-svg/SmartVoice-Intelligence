# SmartVoice Android

تطبيق Android أصلي مبني باستخدام Kotlin وJetpack Compose.

## المتطلبات
- Android Studio حديث يدعم Android Gradle Plugin 8.7.3.
- JDK 17.
- Android SDK Platform 35.

## فتح المشروع
1. افتح Android Studio.
2. اختر **Open** وحدد مجلد `android/` داخل المستودع.
3. انتظر مزامنة Gradle.
4. شغّل مهمة `app > Tasks > build > assembleDebug` أو شغّل التطبيق على جهاز/محاكي.

## الحزمة
`com.smartvoice.intelligence`

## الحالة الحالية
الإصدار 0.2.0 يضيف تسجيل الصوت محلياً بصيغة M4A/AAC، وطلب إذن الميكروفون عند بدء التسجيل فقط، وسجلّاً للتسجيلات مع التشغيل والحذف. تُحفظ الملفات داخل مساحة التطبيق الخاصة (`filesDir/recordings`) ولا تُرفع إلى خادم.

لم يُنفّذ التفريغ النصي أو تحليل السياق أو المزامنة السحابية بعد. ولم يتم تأكيد نجاح بناء APK في بيئة التطوير حتى الآن.

## الخطوات التالية
1. اختبار التسجيل والتشغيل على جهاز Android فعلي.
2. إضافة قاعدة بيانات محلية لبيانات التسجيلات ومددها.
3. إضافة تفريغ نصي مع الطوابع الزمنية بعد تحديد محرك التفريغ وسياسة الخصوصية.
4. بناء محرك فهم السياق وتوجيه العناصر إلى أقسام التطبيق.
5. إضافة مراجعة بشرية للعناصر غير المؤكدة.
